MINI TRADER ACADEMY — PWA 1.0

CONTENIDO
- index.html: aplicación educativa.
- manifest.webmanifest: nombre, icono y ajustes de instalación.
- sw.js: caché para abrir la app sin conexión después de la primera visita.
- icons/: iconos Android.

IMPORTANTE
Para instalar como PWA, el sitio debe publicarse mediante HTTPS (o probarse en localhost).
Abrir index.html directamente como archivo no permite instalarla como PWA.

PUBLICACIÓN SENCILLA CON GITHUB PAGES
1. Crea/inicia sesión en GitHub.
2. Crea un repositorio público, por ejemplo mini-trader-academy.
3. Sube TODOS los archivos y carpetas de este paquete, manteniendo la estructura.
4. En Settings > Pages, selecciona Deploy from a branch, branch main y folder /(root), y guarda.
5. Espera a que GitHub Pages publique el sitio HTTPS.

INSTALAR EN MOTOROLA
1. En el Motorola, abre Google Chrome y visita la dirección HTTPS publicada.
2. Pulsa “Instalar aplicación” si aparece, o menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.
3. Confirma. Aparecerá el icono Mini Trader en la pantalla de inicio.
4. Abre la app una vez con internet. Luego la interfaz se puede abrir sin conexión.

PROGRESO
Las lecciones, puntos y respuestas se guardan con localStorage en ese teléfono y navegador.
No borres los datos del sitio ni uses modo incógnito; si borras los datos de Chrome, puedes perder el progreso.
El progreso no se sincroniza entre teléfonos.

EDUCACIÓN Y SEGURIDAD
Contenido educativo para practicar conceptos. No contiene conexión con brokers, cotizaciones reales ni órdenes. No usar dinero real.
